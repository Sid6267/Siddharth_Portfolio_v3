# Siddharth Tiwari — Interactive Portfolio v2

A high-motion, application-ready portfolio inspired by the uploaded Reel: cinematic hero, animated typography, pinned scroll sections, horizontal work showcase, parallax, counters, magnetic controls, responsive mobile layout, and a real resume PDF.

## Files
- `index.html` — portfolio
- `style.css` — visual system and responsive styles
- `script.js` — GSAP/ScrollTrigger interactions + accessible reduced-motion fallback
- `assets/Siddharth_Tiwari_Resume(20261002-171746).pdf` — resume generated from the uploaded DOCX

## Deploy
This is a static site. Upload the folder to Vercel/Netlify/GitHub Pages or connect the folder/repository to Vercel.

## Important before public use
1. Replace the LinkedIn and Tableau Public placeholder destinations in `index.html` with your exact profile URLs.
2. Add real dashboard screenshots and links for the selected-work cards if you want those cards to open into case studies.
3. If desired, replace the abstract ST hero artwork with a professional headshot.

## Motion
GSAP 3.12.5 and ScrollTrigger are loaded from jsDelivr. If the CDN is unavailable, the page still renders and retains a reduced/basic layout rather than becoming unusable.
